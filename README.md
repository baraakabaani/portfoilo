### 🚀 Featured projects

**GraphRAG Research Assistant — PDF Paper Retrieval Agent**
Hybrid retrieval + GraphRAG over a 100-paper corpus (MongoDB, Qdrant, Neo4j) behind a FastAPI backend, Docker Compose–orchestrated. QLoRA fine-tuned Llama-3.2-1B, raising citation rate from ~30% to ~85% and faithfulness from 0.41 to 0.67. Full hybrid pipeline reached NDCG@5 = 0.661.
`Python · FastAPI · Qdrant · Neo4j · MongoDB · Docker Compose · Hugging Face · QLoRA/PEFT`

**RAG System — Respiratory Infection Knowledge Assistant**
End-to-end clinical RAG pipeline (ingestion → chunking → semantic retrieval → grounded generation). Added cross-encoder reranking, lifting Recall@1 from 0.60 to 0.80 and grounding score from 0.608 to 0.708.
`Python · Sentence Embeddings · Vector DB · Cross-Encoder Reranker`

**Bilingual Traffic Sign Recognition (ViT + OCR)**
Fine-tuned ViT-Base on ~12k real UAE/Jordan traffic sign images (29 classes) → 94.82% accuracy. Added EasyOCR as a bilingual (Arabic/English) redundancy layer; robustness-tested under fog, low-light, noise & occlusion with Grad-CAM explainability.
`Python · PyTorch · ViT · EasyOCR · Grad-CAM · OpenCV`

**AI-Based Ultrasonic Attendance System** *(Capstone)*
Attendance verification via inaudible ultrasonic chirps (20–21 kHz) and a Goertzel-based detector. On-device XGBoost classifier (F1 = 0.886, AUC = 0.969) flags spoofed attendance, backed by biometric confirmation and live Firebase Firestore sync.
`Flutter/Dart · Kotlin · XGBoost · Goertzel DSP · Firebase Firestore`

**Full-Stack Recruiting Platform + LinkedIn Import Extension**
Recruiting platform for job postings, applications, and candidate profiles, paired with a browser extension that auto-imports LinkedIn candidate data to cut manual entry.
`JavaScript · REST APIs · Browser Extensions`
